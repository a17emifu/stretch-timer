# ストレッチタイマー / Stretch Timer

**現行バージョン: v0.3.2**

ストレッチのメイン時間とインターバル時間を、一時停止または停止するまで無限ループする Web タイマー。単一 HTML ファイルで完結し、外部依存なし（Google Fonts の CDN のみ参照）。

## 特長

- **プリセット3種をワンタップ切替**: STANDARD (30s/5s) / QUICK (20s/4s) / SHORT (10s/4s)
- 準備カウント秒 = インターバル秒（プリセットに連動して 4s または 5s）
- メインとインターバルで効果音を完全に分離（音域差 約 10 倍）
- **音量スライダー (0〜100, 初期値50)** — 50 が従来比同等。設定は localStorage に保存され次回起動時に復元
- すべての効果音は Web Audio API で合成生成 — 外部音声ファイル不要
- メイン終了 → インターバル開始の間に 1 秒の「間」
- カウントダウン音（残り 3, 2, 1 秒）、開始音、終了音を自動制御
- PC・スマートフォン両対応 / 縦横どちらの向きでも表示破綻なし
- Wake Lock API による画面スリープ抑止（対応ブラウザのみ）
- キーボード操作対応（Space = 再生/一時停止、Esc = 完全停止、1/2/3 = プリセット切替、音量スライダーフォーカス中の↑↓で5刻み調整）

## 使い方

1. `index.html` をブラウザで開く（PC でもスマホでも可）
2. 必要に応じて音量スライダーで音量を調節
3. 上部の3つのプリセットカードから任意のものをタップ
4. ▶ ボタンで開始 — インターバル秒数と同じ秒数の準備カウント後にメイン時間がスタート
5. メイン → インターバル → メイン … と無限ループ
6. 一時停止または完全停止で中断

## デプロイ

GitHub Pages で公開する場合の URL:

```
https://<ユーザー名>.github.io/<リポジトリ名>/
```

スマートフォンからアクセス後、ブラウザの共有メニューから **「ホーム画面に追加」** することでアプリのように起動できる。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 最新版の本体（中身は現行バージョンと同一） |
| `ストレッチタイマー_vX.Y.Z.html` | 各バージョンのアーカイブ |
| `ストレッチタイマー_デザインモック_vX.Y.Z-mockN.html` | デザイン検証用モック |
| `機能概要` | 原仕様書 |

新バージョンを追加する際は `index.html` を上書きし、旧版は `ストレッチタイマー_vX.Y.Z.html` として残すこと。

## 変更履歴

### v0.3.2 — 最新
- **ヘッダレイアウトを 3 カラム 1 行構成に統合**
  - `Stretch Timer` タイトル / 音量バー / バージョン番号を同じ 1 行に配置
  - 音量バーは flex で可動幅を確保し、中央部分を伸縮
  - スマホ幅（≦380px）でも 1 行を維持するため、アイコン・数値・バージョン表記を小型化
- 機能・効果音・タイマー挙動はすべて v0.3.1 と同一

### v0.3.1
- **プリセットのインターバル時間を一律 4 秒以上に統一**
  - QUICK: `20s / 3s` → **`20s / 4s`**
  - SHORT: `10s / 3s` → **`10s / 4s`**
  - STANDARD: `30s / 5s`（変更なし）
  - 準備カウント秒 = インターバル秒の仕様により、QUICK/SHORT の準備秒も 3s → 4s へ自動変更
- **インターバルカウントダウン音（残り 3, 2, 1 秒）の音量を約 40% 増**
  - ローパス通過の温かい音質を維持したまま、知覚音量を引き上げ
  - 内部値: gain `0.28 → 0.392`, `0.20 → 0.28`（共に 1.4 倍）
- **音量調節 UI を追加**
  - ヘッダ下に音量スライダー（0〜100, 初期値 50）
  - スケール式: `masterGain = (slider / 100) × 1.4`
    - `0` = ミュート、`50` = 従来音量（0.7）と等価、`100` = 最大（1.4）
  - 音量に応じてアイコンが変化（ミュート / 小 / 中 / 大）
  - 設定は `localStorage` に保存され、次回起動時に復元
  - キーボード ↑/↓ /←/→ で 5 刻み調整可能（スライダーフォーカス時）

### v0.3.0
- ブランド名を `Stretch Tempo` から `Stretch Timer` に変更（イタリック解除）
- メイン/インターバル時間を 3 種プリセットのワンタップ切替に変更
  - STANDARD (30s / 5s) — デフォルト
  - QUICK (20s / 3s)
  - SHORT (10s / 3s)
- 手動入力欄（0–60 秒、3–10 秒のスピンボタン）を削除
- 準備カウント秒数 = インターバル秒数 に変更（従来は固定 3 秒）
- ヒント文「最初に○秒のカウントが入ります」もプリセット連動
- キーボードショートカット `1` / `2` / `3` でプリセット切替

### v0.2.1
- メインのカウント音（残り 3, 2, 1 秒の音）が高すぎて耳に刺さる問題を修正
- 1320Hz square + 2640Hz sine → 784Hz triangle (G5) + 1175Hz sine (D6) に変更

### v0.2.0
- メイン用とインターバル用の効果音を完全に再設計し、音域・音色レベルで明確に分離
  - メイン = 高音域 (1000–2600Hz)、明るい金属／ベル系
  - インターバル = 低音域 (100–330Hz)、ローパス通過の温かい木質／パッド系
- メイン終了からインターバル開始までに 1 秒の間を追加

### v0.1.1
- メイン → インターバルの遷移バグを修正(2サイクル目以降に進まなかった問題)

### v0.1.0
- 初版

## 技術スタック

- 単一 HTML ファイル / バンドラ・ビルドステップなし
- Web Audio API（OscillatorNode + BiquadFilterNode + GainNode）による効果音合成
- `requestAnimationFrame` + `performance.now()` による精密タイマー
- `localStorage` による音量設定の永続化
- `navigator.wakeLock` による画面スリープ抑止
- フォント: Fraunces / Manrope / JetBrains Mono（Google Fonts）

## 動作確認環境

- Windows 11 / Chrome, Edge
- Android / Chrome
- iOS / Safari（Wake Lock は未対応）
