# ストレッチタイマー / Stretch Tempo

**現行バージョン: v0.2.2**

ストレッチのメイン時間とインターバル時間を、一時停止または停止するまで無限ループする Web タイマー。単一 HTML ファイルで完結し、外部依存なし（Google Fonts の CDN のみ参照）。

## 特長

- メイン時間 0〜60 秒、インターバル時間 3〜10 秒で設定可
- メインとインターバルで効果音を完全に分離（音域差 約 10 倍）
- すべての効果音は Web Audio API で合成生成 — 外部音声ファイル不要
- メイン終了 → インターバル開始の間に 1 秒の「間」
- カウントダウン音（残り 3, 2, 1 秒）、開始音、終了音を自動制御
- PC・スマートフォン両対応 / 縦横どちらの向きでも表示破綻なし
- Wake Lock API による画面スリープ抑止（対応ブラウザのみ）
- キーボード操作対応（Space = 再生/一時停止、Esc = 完全停止）

## 使い方

1. `index.html` をブラウザで開く（PC でもスマホでも可）
2. メイン時間・インターバル時間を任意に設定
3. ▶ ボタンで開始 — 3 秒の準備カウント後にメイン時間がスタート
4. メイン → インターバル → メイン … と無限ループ
5. 一時停止または完全停止で中断

## デプロイ

GitHub Pages で公開する場合の URL:

```
https://<ユーザー名>.github.io/<リポジトリ名>/
```

スマートフォンからアクセス後、ブラウザの共有メニューから **「ホーム画面に追加」** することでアプリのように起動できる。

## ファイル構成

| ファイル / ディレクトリ | 役割 |
|---|---|
| `index.html` | 最新版の本体（中身は現行バージョンと同一） |
| `ストレッチタイマー_vX.Y.Z.html` | 各バージョンのアーカイブ |
| `manifest.json` | Web App Manifest（ホーム画面追加時のアイコン・名称設定） |
| `icons/` | ホーム画面アイコン用PNG群 |
| `機能概要` | 原仕様書 |
| `README.md` | このファイル |

新バージョンを追加する際は `index.html` を上書きし、旧版は `ストレッチタイマー_vX.Y.Z.html` として残すこと。

## 変更履歴

### v0.2.2 — 最新
- ホーム画面アイコン用のPNG（192/512/180）と `manifest.json` を追加
- iOSの `apple-touch-icon`、Androidの `Web App Manifest` 両方に対応
- スマホで「ホーム画面に追加」したときに専用アイコン・名称で起動

### v0.2.1
- メインのカウント音（残り 3, 2, 1 秒の音）が高すぎて耳に刺さる問題を修正
- 1320Hz square + 2640Hz sine → 784Hz triangle (G5) + 1175Hz sine (D6) に変更

### v0.2.0
- メイン用とインターバル用の効果音を完全に再設計し、音域・音色レベルで明確に分離
  - メイン = 高音域 (1000–2600Hz)、明るい金属／ベル系
  - インターバル = 低音域 (100–330Hz)、ローパス通過の温かい木質／パッド系
- メイン終了からインターバル開始までに 1 秒の間を追加

### v0.1.1
- メイン → インターバルの遷移バグを修正(2サイクル目以降に進まなかった問題)

### v0.1.0
- 初版

## 技術スタック

- 単一 HTML ファイル / バンドラ・ビルドステップなし
- Web Audio API（OscillatorNode + BiquadFilterNode）による効果音合成
- `requestAnimationFrame` + `performance.now()` による精密タイマー
- `navigator.wakeLock` による画面スリープ抑止
- フォント: Fraunces / Manrope / JetBrains Mono（Google Fonts）

## 動作確認環境

- Windows 11 / Chrome, Edge
- Android / Chrome
- iOS / Safari（Wake Lock は未対応）
